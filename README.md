# BLAZE TV Splash

Animated TV power-on splash logo for **BLAZE TV**, with CRT effects and Web Audio sound.

## Run

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080` and click **Start Broadcast**.

## Features

- TV power-on beam + static noise sequence
- Gradient Orbitron wordmark with pulse / glow / glitch
- Synthesized audio: static, power-on hum, logo chord hit
- Mute + replay controls
- Reduced-motion friendly fallback
