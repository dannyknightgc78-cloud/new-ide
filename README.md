# PINNACLE

Invented companion app for Europe's elite club competition — live nights, the path to the final, and the clubs still standing.

## Run

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## What's inside

- **Home** — full-bleed stadium hero with brand-first composition
- **Tonight** — live scoreline + quarter-final fixtures
- **Path** — knockout bracket from R16 to the final
- **Clubs** — league-phase table and club list

Demo data only — not affiliated with UEFA.
