Silent protection for Safari

Hardly noticeable. Parent installs once — kid uses normal Safari. Haven blocks ads and popups in the background.

1

Install content filter

Tap Install DNS filter → Settings → Allow. Works silently in Safari.

2

Enable Safari content blocker

Settings → Safari → Extensions → Haven. No toolbar UI — just blocks ads and adult domains.

3

Optional — portal tiles

Share → Add to Home Screen only if you want Admin-approved site shortcuts. Otherwise skip — Safari is enough.

Once installed, Haven works silently — no app to open.
